## Featured Projects

### 🛡️ [Drug Safety Guard](https://github.com/Ashmit-Singh/drug-safety-guard)
A clinical decision support system that catches harmful drug combinations at the **ingredient level** — not just known brand pairs — before a doctor signs off. The hard part was designing an O(n²·m²) ingredient-pair detection algorithm that stays fast enough for real-time prescription review, solved via Redis caching with 24h TTL for sub-millisecond lookups. Backed by PostgreSQL triggers, a Cassandra audit trail with 2-year retention, Supabase RLS across 14 tables, and full Docker/Kubernetes containerisation.

`Flutter` `Node.js` `PostgreSQL` `Redis` `Cassandra` `Docker`

---

### 🔬 [Psoriasis Image Classifier](https://github.com/Ashmit-Singh)
An EfficientNetB0 + DenseNet121 ensemble trained to classify psoriasis severity across **13 classes on ~886 images** — a dataset small enough that architecture choices and augmentation strategy mattered more than raw compute. Achieved **88% validation accuracy**. The anchor project across my research internship applications.

`PyTorch` `EfficientNetB0` `DenseNet121` `OpenCV`

---

### 📄 [Document Vision Pipeline](https://github.com/Ashmit-Singh)
End-to-end document intelligence: YOLOv8 detects and localises regions, OpenCV handles preprocessing, Tesseract OCR extracts text. Built to handle real-world document noise — skew, shadows, variable fonts — not clean scans.

`YOLOv8` `OpenCV` `Tesseract OCR` `Python`

---

### 🔍 [Semantic Search](https://github.com/Ashmit-Singh)
Dense retrieval over custom corpora using FAISS and Sentence Transformers. Indexes embeddings locally for fast approximate nearest-neighbour search without a vector DB dependency.

`FAISS` `Sentence Transformers` `Python`

---

### 📷 [QR Scanner](https://qr-scanner-nu-six.vercel.app)
Cross-platform Flutter QR scanner running on Android, iOS, Linux, macOS, and Web from a single codebase — live on Vercel. No permissions bloat, no ads.

`Flutter` `Dart` `Vercel`
